# Soft Embrace — Reply

Web app (PWA) để chọn và copy tin nhắn trả lời khách Instagram.

- `dist/` — bản build chạy được (index.html, sw.js, manifest, icons)
- `src/` — mã nguồn (app.js, app.css, index.src.html, data.json)
- `build.py` — `python3 build.py` ghi ra `dist/`
- `docs/` — design spec, audit thiết kế, audit performance, fix report
- `shots/` — ảnh chụp màn hình khi test (393×852 và 430×932)
